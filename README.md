# CloudWRX — Business owner site

Website: https://cloudwrxaidata.com/

Static website: publish GitHub Pages from main / (root). No build, database, API keys or server required. Keep CNAME and .nojekyll at the repository root.

## Referral links

Share https://cloudwrxaidata.com/?ref=YOUR_CLOUDWRX_CODE . referral.js preserves the incoming code in the provider actions and cross-site links. Codes are case-sensitive and allow letters, digits, underscores and hyphens, up to 64 characters. The default is bbq4pucskp only when ref is absent. Invalid explicit codes disable the referral actions and show a correction message. No visitor cookie overrides an incoming code.

## Editing

Edit index.html, page.css, enhancement.css, interaction.css, page.js, interaction.js and referral.js as needed. Artwork is in assets/. Preserve the supplied calculator assumptions and disclosures.

## Verification

Check desktop and mobile layout, videos, menu, section navigation, image dialogs and calculators. Open with a real provider code and inspect all provider/signup and cross-site links. Verify the provider's attribution independently. This site does not collect leads or business records, or determine eligibility.
